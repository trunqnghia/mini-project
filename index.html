Chào Mừng Đến Với Khoá Học Web Căn Bản

Trang web này tóm tắt các khái niệm nền móng cốt lõi mà bất kỳ nhà phát triển web nào cũng cần nắm vững khi bước chân vào thế giới lập trình.

1. Các Khái Niệm Cơ Bản

Internet

Hạ tầng mạng lưới phần cứng khổng lồ toàn cầu, kết nối hàng triệu máy tính lại với nhau để truyền tải dữ liệu.

Web (World Wide Web)

Một không gian thông tin, một dịch vụ chạy trên nền tảng Internet giúp người dùng truy cập tài liệu qua các liên kết (URL).

Website

Tập hợp gồm nhiều trang web (webpages) liên quan, chung một tên miền và được lưu trữ trên máy chủ. Giống như một cuốn sách hoàn chỉnh.

Trang web (Webpage)

Một file văn bản đơn lẻ (như file .html này) hiển thị trên trình duyệt. Giống như một trang sách nằm trong cuốn sách.

2. Mô Hình Browser & Web Server

Trình duyệt (Web Browser): Phần mềm cài trên máy người dùng (Client) như Chrome, Cốc Cốc, chịu trách nhiệm gửi yêu cầu (Request) và dịch mã nguồn HTML/CSS/JS thành giao diện.

Máy chủ Web (Web Server): Máy tính chứa phần mềm (Nginx, Apache) chạy liên tục 24/7, chịu trách nhiệm lưu trữ mã nguồn và phản hồi (Response) dữ liệu lại cho trình duyệt.
