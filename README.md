# Mini-project 1: Website Nhập Môn Web Căn Bản

## 🎯 Mục tiêu dự án
Dự án này được xây dựng nhằm tóm tắt tổng quan và phân biệt rõ ràng các khái niệm cơ bản trong lập trình phát triển Web bao gồm: Internet, Web (WWW), Website, Trang web (Webpage), Trình duyệt (Browser) và Máy chủ (Web Server).

## 📁 Cấu trúc thư mục kho lưu trữ
- `index.html` — Trang chứa nội dung bài tóm tắt và cấu trúc HTML chính.
- `css/style.css` — Định dạng giao diện, bố cục lưới (Grid) hiển thị trực quan.
- `js/script.js` — Thư mục chứa các tệp xử lý logic tương tác (nếu có).
- `assets/` — Thư mục chứa hình ảnh và tài nguyên đa phương tiện phụ trợ.

## 🚀 Công nghệ sử dụng
- **Semantic HTML5** (header, main, section, nav,...)
- **CSS3 Flexbox & Grid** tạo giao diện tự động co giãn.
